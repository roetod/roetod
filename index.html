About

I'm a developer and student from Iran, studying in the technical and vocational education system. I started with frontend design and kept pulling the thread until I was working across the whole stack.

On the backend I work with Python, focusing on Django, Django REST Framework and FastAPI. On the desktop side I write C# and .NET: WPF apps like a task manager and a 2048 game, and WinForms tools like an invoicing and accounting app.

Web security is the part I enjoy most. I've gone through the OWASP Top 10 and PortSwigger's Web Security Academy, completed an internship in the field, and I'm exploring a path toward SOC analysis, which is why I'm building up my networking and Python-for-security fundamentals.

Away from the keyboard, videography and video editing are my longest-running interest, along with photography. I also love film, music and football, and I play mobile games when I need a break.

Skills

Frontend

I design and build interfaces with HTML, CSS and JavaScript, from layout and typography to small, purposeful animations. I care about responsive behavior, light and dark themes, accessibility basics like focus states and reduced motion, and I've built right-to-left and multilingual sites, including a large static Persian lesson site.

Backend

I write server-side code in Python and study Django, Django REST Framework and FastAPI. That covers designing REST APIs, structuring models and routes, validating input, and keeping data in JSON files or databases. I'm working toward building complete, deployable backends for my own frontends.

Desktop apps

With C# and .NET I build Windows applications in WPF and WinForms: multi-page task and notes managers, a 2048 game, and an invoicing and accounting app. I'm comfortable with data binding, file dialogs, form navigation, JSON persistence and the object-oriented structure that keeps these apps maintainable.

Web security

I study how web applications break so I can build ones that don't. I've worked through the OWASP Top 10 and PortSwigger's Web Security Academy, including injection, broken access control and authentication flaws, and I apply that thinking to my own code. I'm also exploring the SOC analyst path, with networking and Python for security tooling.

Photo & video

Videography and editing are my longest-running creative interest. I shoot, cut and finish footage, and I do photography alongside it. Working with framing, light and pacing has shaped how I design interfaces, with the same attention to composition and detail.
